About CK

WebGLやWebGPUを中心としたインタラクティブ表現の最小事例検証コンテンツ「ck」（https://nulldesign.jp/review/）。
依存性を排除したシンプルな設計をベースに、「小さく、早く」を徹底した実験と検証を重ねる実践的なプロジェクト。

かつてJavaScriptの使い方を探していた「.log」に対し、CKはWebGPUをはじめとする次世代クリエイティブへの本格的なシフトと転換を象徴する場となります。
ということも考えつつ、本当は本業の気分転換としてなんとなく描いている環境です。

"ck" (https://nulldesign.jp/review/) is a minimal proof-of-concept project centered on interactive expression using WebGL and WebGPU.
Built on a simple, dependency-free design, it is a hands-on project that repeatedly experiments and iterates under a strict "small and fast" principle.

Where ".log" once explored ways of using JavaScript, CK stands as a symbol of a full-fledged shift toward next-generation creative technology, beginning with WebGPU.
That said, honestly, this is really more of a space where I draw things somewhat casually, as a break from my day job.
